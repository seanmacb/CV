\textbf{Target-of-Opportunity Searches:}
I have led numerous observing campaigns using different telescopes and facilities, with the goal of detecting to electromagnetic counterparts to gravitational wave merger events. Starting in 2023, I co-led the \DESGW\ program, conducting \DECam\ observations, processing raw image data from 13 \ToO\ campaigns to calibrated products, and analyzing processed data in response to \IGWN\ Observing Run 4 (O4) triggers.
When a well-localized gravitational-wave merger candidate was accessible to both Northern and Southern hemisphere instruments, I led a collaboration between \DESGW\ and the \JGEM. In this collaboration, I obtained multi-epoch photometry using \DECam, processed the obtained data, and cross-matched this data with spectroscopic observations using \PFS\ at Subaru Telescope, enabling the first public scientific result using \PFS\ \citep{Zhang2025S250328ae}.

Since 2025, I have been leading the \Rubin\ \ToO\ observing program as the \Rubin\ \ToO\ observer. In this role, I have led observing responses to one interstellar object \citep{Chandler_2026}, one high-energy neutrino event (later reclassified as terrestrial), and two gravitational-wave merger candidates, including the deepest wide-area gravitational wave \ToO\ search to date ($m_{r,5\sigma}\sim24.4$ across $\sim800\deg^2$ on four nights, see Figure~\ref{fig:highlights:s251112cm_search}) \citep{Andreoni2024RubinToO,MacBride2026RubinToO}. % Rubin ToO
